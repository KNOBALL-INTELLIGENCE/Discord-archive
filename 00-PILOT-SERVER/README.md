## How the boys should use this repo

1. Start at the root `README.md`.
2. Use this Pilot guide for current server context.
3. Use readable `.txt` transcripts when available.
4. Use direct Discord message links inside transcripts to jump back to the live/original conversation.
5. Treat full-server JSON as source evidence for SARA and processing, not as the normal human browsing surface.

## Source rule

A Discord message is evidence of what was said. It is not automatically:
- a Knoball-wide decision;
- a current league rule;
- approved product architecture;
- an adopted roadmap item;
- a SARA operating control.

Those relationships are established separately through reconciliation against the authoritative owning surface.

## Future Pilot tenant repo

When the Pilot receives its own league repository, cleaned/normalized league knowledge can migrate there with source provenance back to this archive. This repository remains the evidence/intake source unless a later approved architecture explicitly replaces that role.
